# 产品定位与使用方式

## 为谁解决什么问题

积木三视图实验室是一个通用的三视图与空间探索工作台。观察、练习、搭建三大模式平级，可独立使用，用于理解立体与二维投影的关系、检验空间假设，以及创作积木模型。

教师课堂演示、学生独立练习、家长陪孩子学习和个人空间探索都属于适用场景。家长陪约 6–12 岁孩子辨认方向、理解遮挡，是常见用法之一，不是年龄或用途限制。工具不要求选择身份、建立账号或完成固定课程。

练习可独立进行，也可用于共同讨论；记录供使用者或陪学者回顾，不作考试评分、能力诊断或儿童排名。工具使用立方积木表达空间关系，不承担专业 CAD 的工程尺寸制图。

## 独立使用与共同讲解

默认打开简单难度、边长 4 的“三层台阶”示范。使用者可直接观察，也可随时进入练习或搭建。观察模式中的“用这个模型练习”保留当前观察结构并进入画三视图，不换成另一道随机题。

“讲解提示（家长/老师）”是可选辅助内容，用于提出具体问题、鼓励说出理由，再操作核对。独立使用时可以不展开提示；共同学习时，成人或同伴也可操作页面并组织讨论。参考答案可用于自查和讲解，查看后如实记为参考学习。

教程通过 `?` 按需打开，不在首次访问自动弹出，也不要求先完成教程才能使用工具。

在手机上，可选择正视图、左视图或俯视图，一次关注一幅。需要核对立体结构时使用回看模型入口，再返回原图继续；视图选择与模型切换保留已有图纸内容。

## 一条可选的学习路线

以下顺序适合初次学习投影关系，包含练习模式的两种任务。它是使用建议，不是必经流程；已有明确问题时，可以直接打开任意模式。

### 1. 观察范例：建立方向感

可以先用默认的三层台阶示范，也可选更小的边长 3 空间。固定范例便于重复比较，随机结构则提供新的观察对象。

| 范例 | 标识 | 可以提出的问题 |
| --- | --- | --- |
| 三层台阶 | `stairs` | 从前面看有几层？换到左边后，哪些积木重叠了？ |
| 转角积木 | `corner` | 为什么前面和左边可能看到相同轮廓？这说明方向相同吗？ |
| 两座小塔 | `towers` | 哪幅视图能看出两座塔之间的空位？哪些方向会把它们重叠起来？ |

先预测“这一面能看到哪几块”，再切换前、左、上视角核对；共同讲解时可请学习者指一指并说理由。俯视图用于观察占地，正视图和左视图用于观察对应方向的高度与遮挡。颜色帮助看层次，但不是作答条件。

### 2. 画三视图：把观察变成表达

选择一幅图，判断每个格子为什么要填或留空，再操作验证。三幅网格完成后检查；漏填和多填分别显示，可以回到模型查找原因，再提交同一题。既可独立练习，也可由家长或教师围绕具体格子提问。

重点不是一次答对，而是能说出“这个格子为什么有投影”或“那块积木为什么被挡住”。同一题的多次检查不会增加题数；更正后答对会更新原记录。

### 3. 按三视图还原：组合二维线索

根据给定三视图，用 3D 场景或俯视搭建盘放置积木。可先满足占地，再观察两幅侧向投影，逐步调整高度。讲解时可以问“哪幅图能告诉我们积木放在哪里”。所有非底层积木都需要正下方支撑。

判断标准是三幅投影都一致。两个不同的合法积木结构可能对应同一组三视图，这些解都应该通过。参考结构只是一种解，可以继续寻找另一种解，并解释“哪里变了，为什么三张图没变”。

### 4. 自由搭建：主动验证规律

自由创建模型，也可提出问题，例如“加一块积木，能不能只改变一幅视图？”先作预测，再搭建和验证。可使用剖切观察内部，但剖切仅改变显示，不会删除积木或改变投影判定。

自由作品自动保存在当前浏览器，可恢复继续搭建。导出 JSON 用于备份或转移设备，导入前会校验整个文件。最多保留 80 步撤销，可撤销缩小空间、导入和其他搭建操作；撤销历史不会随刷新保存。

## 难度与反馈

空间边长可选 3–8，默认为 4、简单难度。随机题提供四档难度，积木数量同时随空间尺寸调整。使用者可直接选择合适的复杂度，不需要逐级解锁；界面不会根据记录划分能力等级。

练习记录仅覆盖最近 200 道题，显示已练、独立完成和参考完成。查看答案后的当前题始终属于辅助学习，即使随后提交正确也不算独立完成。打开新题会建立新的题目标识，检查或查看答案后才纳入记录；反复检查当前题只更新该题。

这些记录帮助使用者回顾近期练习，也方便家长或教师回看讨论过的内容，不是终身成绩。记录仅在同一浏览器、同一站点可见，不进行云同步。清除练习记录不会删除自由作品；更换设备前应先导出作品文件。

## 交互与讲解原则

- 观察、练习、搭建平级且可独立使用，不以身份选择或固定课程限制入口。
- 可选讲解提示帮助家长和教师提问，也支持独立使用；反馈指向具体格子或投影关系。
- 观察方向、坐标标签、3D 相机、二维网格和语音说明必须一致。
- 不把参考答案包装成独立完成，也不把唯一示例结构当作唯一正确答案。
- 鼠标、键盘与触摸都应能完成核心流程；手机逐幅查看时保留图纸状态，并提供方便的回看模型入口。语音是辅助，不能成为理解任务的唯一途径。
- 本地存储失败时继续允许操作，同时说明无法长期保存，并提供文件导出。

## 当前边界与改进方向

当前版本保存最近一件自由作品，不提供作品云库、班级账号、跨设备进度同步或教师统计后台。作品 JSON 不含练习记录，导出不能迁移近期题目统计。自动化测试主要基于 Chromium；Safari、微信内置浏览器和真实移动设备仍应逐次记录验证结果。

后续改进围绕真实使用反馈：模式是否容易找到，能否解释方向与遮挡，反馈是否帮助纠错，手机切换是否保留上下文，讲解提示是否方便教师和家长。新增功能应保持通用探索能力，并保留静态、易部署、无需账号的使用方式。
