## 核心学习流程

- [ ] 观察、练习、搭建平级且可直接使用，不要求身份选择、年龄限制或按顺序完成课程。
- [ ] “讲解提示（家长/老师）”为可选辅助内容；教程仅通过“使用帮助”按需打开，首次访问不自动弹出。
- [ ] 三方向入门演示保持同一模型，前、左、上观察与投影对应；退出后能继续自由操作。
- [ ] 默认展示简单难度的三层台阶；“用这个模型练习”保留当前观察模型与空间尺寸并进入绘图，不替换为随机题。
- [ ] 手机逐幅选择正视图、左视图、俯视图后能回看模型；切换时保留已画内容，明确换题时才初始化图纸。
- [ ] 检查按钮位于投影旁；桌面可对照模型作答，手机能够完成观察、画图、还原、搭建与文件操作。
- [ ] 辅助观察有明确参考学习提示，使用后本题不计独立完成；普通显示切换不覆盖图纸。
- [ ] 参考答案在独立弹窗显示，开关前后三幅作答完全一致；弹窗可用键盘关闭并恢复合理焦点。
- [ ] “清空三幅”可撤销，恢复三幅原稿；重新涂格或换题后撤销清空失效，辅助标记不会因此重置。
- [ ] 未完成且已有作答时，改尺寸、改难度、切换练习类型、离开练习和新题都先确认；取消后保持原题与内容。
- [ ] 在 3D 场景和俯视盘分别测试：主键执行当前工具，右键临时减少且不改变工具；触摸和键盘激活按工具执行。
- [ ] 依次完成观察范例、画三视图、按三视图还原和自由搭建；核对三个范例与前、左、上方向。
- [ ] 验证边长 3、4、8 与四档难度；检查生成结构的边界和正下方支撑。
- [ ] 验证还原任务接受投影相同的不同合法结构，颜色不影响判题。
- [ ] 同题多次检查不增加题数；答错后答对更新原记录；使用辅助观察或查看答案后不计独立完成。
- [ ] 确认统计标为最近 200 题内记录，可供自己、家长或教师回顾，不显示考试成绩或能力诊断；清除练习记录不会删除作品。
- [ ] 验证自由作品自动保存、刷新后恢复，以及切换到观察或练习后作品仍保留。
- [ ] 验证 JSON 导出导入；越界、重复、悬空、错误版本和过大文件不覆盖原作品。
- [ ] 验证撤销、重做和新操作清空重做分支；缩小空间后撤销能够恢复尺寸与积木。
- [ ] 检查存储被禁用、存储配额不足或已有数据损坏时，页面仍可使用并给出相应保存提示。
- [ ] 普通显示与原生全屏下，支撑不足、保存失败、缩小空间等工作区提示均可见，修正后不会保留误导性旧反馈。
- [ ] 使用键盘完成模式切换、画图和搭建盘操作；检查焦点、弹窗退出及触摸交互。
- [ ] 验证静音、语音失败回退、各模式教程和剖切；确认剖切不改变模型、投影或存档。
- [ ] 帮助直接朗读当前步骤，静音时不播放；其他预录反馈不会在手机布局中错误指向“左边/右边”，失败回退也使用合适文本。
